# SQL Employee Data Analysis

## 📌 Project Overview

This project focuses on analyzing employee data using MySQL. It demonstrates how SQL can be used to retrieve, filter, organize, and analyze employee information.

## 🎯 Objectives

- Analyze employee information by department and role
- Filter employees based on ratings and experience
- Analyze salary information
- Calculate employee bonuses
- Rank employees based on experience
- Work with employee data using different SQL techniques

## 🛠️ Tools Used

- MySQL
- SQL
- MySQL Workbench

## 📚 SQL Concepts Covered

- SELECT and WHERE
- Aggregate Functions
- GROUP BY
- UNION
- Subqueries
- Window Functions
- Views
- Stored Procedures and Functions
- Indexing
- Data Analysis

## 🔍 Key Analysis

The project includes queries to:

- Retrieve employee details and department information
- Analyze employees based on performance ratings
- Identify employees reporting to managers
- Compare employee ratings with the maximum rating within each department
- Calculate minimum and maximum salary by role
- Rank employees based on experience
- Identify employees with more than 10 years of experience
- Calculate employee bonuses based on salary and ratings
- Analyze average salary by continent and country

Through this project, I strengthened my practical understanding of SQL and MySQL and gained experience working with employee datasets
